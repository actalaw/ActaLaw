# Músicas

- `trilha-ambiente.mp3` é gerada por `scripts/gerar-sfx.mjs` (trilha própria e provisória, sem licença de terceiros).
- Para usar uma música sua, coloque o arquivo **na pasta do projeto** (`videos/<slug>/minha-trilha.mp3`) e use `"trilha": {"arquivo": "minha-trilha.mp3"}` no plano. Use só músicas que você tem direito de usar (ex.: biblioteca de áudio do YouTube, Pixabay Music ou trilhas compradas).
- Os arquivos desta pasta (exceto este README) não vão para o git.
